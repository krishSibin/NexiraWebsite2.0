# Nexira Spatial — Company Website

Mapping the future with intelligent geospatial solutions. GIS, IT, and AI for businesses, governments, and communities.

## Tech Stack

- **React 18**
- **Vite**
- **Vanilla CSS** (with modern features)
- **Lucide React** (icons)
- **Framer Motion** (not currently used, but planned) or custom CSS/JS animations.

## Getting Started

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Run development server**:
    ```bash
    npm run dev
    ```

3.  **Build for production**:
    ```bash
    npm run build
    ```

## Project Structure

- `public/`: Static assets (logo, images).
- `src/`: Source code.
  - `main.jsx`: Entry point.
  - `app.jsx`: Root component.
  - `sections/`: High-level page sections (Hero, Services, Cases, etc.).
  - `components/`: Reusable UI components.
  - `hooks/`: Custom React hooks for animations and scroll behavior.
  - `styles.css`: Global styles and design system tokens.

## Deployment

The project is configured for deployment on platforms like Vercel, Netlify, or GH Pages using standard Vite build outputs.
